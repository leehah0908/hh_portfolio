01 — About

소개

원천 데이터 수집부터 데이터 웨어하우스/마트(DW/DM) 설계 및 적재, 서빙까지 데이터 라이프사이클 전반을 엔드투엔드로 주도하는 데이터 엔지니어입니다. Airflow DAG 기반의 파이프라인 구축과 안정적인 운영에 강점이 있으며, 단순히 데이터를 다루는 것을 넘어 실제 비즈니스 요구사항에 맞는 데이터 환경을 고민하고 구축해 왔습니다.

최근에는 LLM을 업무에 적용해 7~10일가량 소요되던 고객사 온보딩 기간을 1일 이내로 단축하고 데이터 품질을 개선했습니다. 이 과정에서 프롬프트 구조화와 토큰 캐싱을 활용해 운영 비용까지 함께 최적화했습니다.

더불어 전사적인 데이터 기반 의사결정을 지원하기 위해, 운영 및 이벤트 지표를 배치 파이프라인으로 산출하여 사내 메신저와 사내 데이터 포탈을 통해 서빙하고 있습니다. 나아가 이벤트 기반의 비즈니스 지표 트래킹 파이프라인을 설계하고, 타 팀이 실시간으로 데이터를 수신할 수 있는 알림 인프라를 구축해 조직 전체의 데이터 활용도를 높이고 있습니다.
